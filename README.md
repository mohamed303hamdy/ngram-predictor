# Sherlock Holmes N-Gram Predictor

A professional Python-based NLP pipeline that builds an N-gram language model using the "Stupid Backoff" algorithm. The model is trained on classic Sherlock Holmes literature from Project Gutenberg and provides next-word predictions via a CLI or a web-based Streamlit interface.

## Requirements
- **Python:** 3.10+ 
- **Environment:** Anaconda or venv
- **Dependencies:** Install via `pip install -r requirements.txt`

## Setup
1. **Clone the repository** to your local machine.
2. **Create a Conda environment**:
   ```bash
   conda create -n sherlock python=3.10
   conda activate sherlock
